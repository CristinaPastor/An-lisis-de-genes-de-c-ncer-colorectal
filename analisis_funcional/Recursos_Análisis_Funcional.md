# Recursos para el análisis funcional

## 1. Introducción

Para ampliar la información sobre las variantes genéticas y los genes relacionados con el cáncer colorrectal, existen diferentes herramientas bioinformáticas y bases de datos públicas.

Estos recursos permiten consultar información sobre la localización de los SNPs, su posible efecto funcional, la expresión génica y las asociaciones descritas en estudios anteriores.

## 2. Herramientas y bases de datos

### 2.1. SNPnexus

Herramienta que permite consultar posibles consecuencias funcionales de las variantes genéticas. Proporciona información sobre su localización, genes próximos y posibles efectos moleculares.

Página web: https://www.snp-nexus.org/

### 2.2. GTEx

Base de datos que proporciona información sobre la expresión de genes en diferentes tejidos humanos. También permite consultar asociaciones eQTL entre variantes genéticas y niveles de expresión génica.

Página web: https://gtexportal.org/

### 2.3. GeneCards

Recurso que recopila información sobre genes humanos, incluyendo sus funciones conocidas, localización cromosómica, expresión y asociaciones con enfermedades.

Página web: https://www.genecards.org/

### 2.4. Open Targets

Plataforma que integra información sobre genes, variantes, enfermedades y posibles dianas terapéuticas, facilitando la exploración de asociaciones biológicas.

Página web: https://platform.opentargets.org/

### 2.5. PubMed

Base de datos bibliográfica que permite localizar publicaciones científicas sobre variantes genéticas, genes y mecanismos moleculares relacionados con el cáncer colorrectal.

Página web: https://pubmed.ncbi.nlm.nih.gov/

## 3. Utilidad de los recursos

La consulta de estas herramientas permite complementar la información recopilada sobre las variantes genéticas y explorar posibles explicaciones funcionales de las asociaciones observadas.

**Nota:** Los recursos descritos se presentan como herramientas de consulta propuestas para el análisis funcional. Su inclusión en este documento no implica que se hayan ejecutado análisis nuevos mediante estas plataformas.
